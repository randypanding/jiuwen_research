# 方向 6：程序合成验证 + 形式化方法用于 LLM 代码

> 搜索方向：程序等价/关系验证理论基础、符号执行与动态验证、LLM 生成代码的规范生成与验证、LLM 代码推理验证。
> 本文件为原始搜集结果，不做分析。

## 学术论文（21 篇）

### A. 程序等价 / 关系验证理论基础（行为等价性判据的形式化基础）

1. **SymDiff: A Language-Agnostic Semantic Diff Tool for Imperative Programs** — Shuvendu K. Lahiri, Chris Hawblitzel, Ming Kawaguchi, Hugo Rebêlo（Microsoft Research），CAV 2012 — https://www.microsoft.com/en-us/research/project/symdiff-differential-program-verifier/overview/ — 基于 Boogie 的双程序差分验证/行为等价检查工具，是"行为等价性自动判据"的经典形式化实现。
2. **Relational Verification Using Product Programs** — Gilles Barthe, Juan Manuel Crespo, César Kunz（IMDEA），FM 2011 — https://software.imdea.org/~jmcrespo/docs/FM2011.pdf — 用乘积程序(product programs)把双程序等价/关系性质规约为单程序验证，是等价判据的核心构造方法。
3. **Thirty-seven Years of Relational Hoare Logic: Remarks on Its Principles and History** — Gilles Barthe 等，arXiv 2020 — https://arxiv.org/pdf/2007.06421 — 系统梳理关系霍尔逻辑（RHL），为程序等价、相似性等双运行性质提供演绎验证基础。
4. **A Relational Program Logic with Data Abstraction and Dynamic Framing** — ACM TOPLAS（DOI 10.1145/3551497）— https://dl.acm.org/doi/fullHtml/10.1145/3551497 — 面向对象程序的通用关系程序逻辑，含链接程序等价证明规则（representation independence）。
5. **S4Eq: Self-Supervised Learning to Prove Equivalence Between Programs via Semantics-Preserving Rewrite Rules** — arXiv 2109.10476，2021 — https://arxiv.org/pdf/2109.10476v1.pdf — 用语义保持重写规则序列证明两程序块等价，神经方法做程序等价的直接尝试。

### B. 符号执行 / 动态验证（行为等价判据的自动化引擎）

6. **KLEE: Unassisted and Automatic Generation of High-Coverage Tests for Complex Systems Programs** — Cristian Cadar, Daniel Dunbar, Dawson Engler（Stanford），OSDI 2008 — 符号执行自动生成高覆盖测试的奠基之作，为行为差异探测提供测试生成基础。
7. **Large Language Model Powered Symbolic Execution** — OOPSLA 2025 — https://mengrj.github.io/pdfs/autobug-oopsla25.pdf — 用 LLM 替代定理证明器作为符号执行推理引擎，直接支撑 LLM 生成代码的路径级验证。
8. **Cottontail: Large Language Model-Driven Concolic Execution for Highly Structured Test Input Generation** — IEEE S&P 2026 — https://www.computer.org/csdl/proceedings-article/sp/2026/606500c046/2bojwAJpW0g — LLM 驱动的混合执行(concolic)引擎，为生成代码生成满足约束的结构化测试输入。
9. **Hybrid Concolic Testing with Large Language Models for Guided Path Exploration** — arXiv 2601.12274，2026 — https://arxiv.org/html/2601.12274v1 — LLM 与混合执行结合，辅助 SMT 求解与路径探索，用于生成代码的行为验证。
10. **Inference-Time Code Selection via Symbolic Equivalence Partitioning** — arXiv 2604.06485，2026 — https://arxiv.org/html/2604.06485v2 — 用反例驱动符号执行搜索使两程序执行结果不同的输入，直接实现行为等价/不等价判定。

### C. LLM 生成代码的规范生成与验证（specification / proof）

11. **SpecGen: Automated Generation of Formal Program Specifications via Large Language Models** — Lezhi Ma, Shangqing Liu, Lei Bu 等，ICSE 2025 — https://arxiv.org/abs/2401.08807v3 — LLM 自动生成前置/后置条件与循环不变式，为验证 LLM 代码提供规范来源。
12. **DafnyBench: A Benchmark for Formal Software Verification** — Stanford，2024 — https://arxiv.org/pdf/2406.08467 — 1000+ Dafny 程序基准，评测 LLM 编写可验证代码能力，是验证代码生成的核心基准。
13. **VerifyThisBench: Generating Code, Specifications, and Proofs All at Once** — arXiv 2505.19271，2025 — https://arxiv.org/html/2505.19271v1 — 端到端评测 LLM 同时生成代码、规范与证明，揭示验证代码生成全链路瓶颈。
14. **CLEVER: A Curated Benchmark for Formally Verified Code Generation** — arXiv 2505.13938，2025 — https://arxiv.org/pdf/2505.13938 — HumanEval 的 161 个 Lean 规范基准，含"规范等价性证明"阶段，直接涉及行为等价判据。
15. **VERINA: Benchmarking Verifiable Code Generation** — ICLR 2026 — https://en.papernotes.org/ICLR2026/code_intelligence/verina_benchmarking_verifiable_code_generation/ — 将可验证代码生成拆为 CodeGen/SpecGen/ProofGen 三任务，规范评估结合定理证明+全覆盖测试。
16. **VeriContest: A Competitive-Programming Benchmark for Verifiable Code Generation** — arXiv 2605.08553，2026 — https://arxiv.org/html/2605.08553v1 — 竞编程式可验证代码生成基准，量化规范/证明生成瓶颈。
17. **ATLAS: Automated Toolkit for Large-Scale Verified Code Synthesis** — arXiv 2512.10173，2025 — https://arxiv.org/html/2512.10173v2 — 自动化合成 2.7K 带机器可检查证明的 Dafny 程序，缓解验证代码训练数据瓶颈。
18. **AlphaVerus: Bootstrapping Formally Verified Code Generation through Self-Improving Translation and Treefinement** — arXiv 2412.06176，2024 — https://arxiv.org/pdf/2412.06176v1 — 自改进框架用验证器反馈迭代生成 Verus 形式化验证代码。

### D. LLM 代码推理验证 / 等价游戏 / 闭环验证

19. **Program Semantic Inequivalence Game with Large Language Models** — arXiv 2505.03818，2025 — https://arxiv.org/html/2505.03818v1 — 以"等价需机器可检查证明 / 不等价需发散输入"的游戏形式，把程序等价判定交给 LLM 并验证。
20. **Towards Verified Code Reasoning by LLMs** — arXiv 2509.26546，2025 — https://arxiv.org/html/2509.26546v2 — 抽取 LLM 推理步骤的形式表示并用验证工具自动核验，防止代码推理幻觉。
21. **Clover: Closed-Loop Verifiable Code Generation** — Stanford University + VMware Research，2024 — https://www.recodaify.com/stanford-researchers-introduce-clover-closed-loop-verifiable-code-generation-that-checks-consistencies-among-code-doc-strings-and-annotations-and-enforces-correctness-in-ai-generated/ — 生成-验证闭环，通过代码/规范/文档一致性检查保证 LLM 生成代码正确性。

## 开源项目（12 个）

1. **KLEE（符号执行引擎）** — Stanford（LLVM 生态）— https://github.com/klee/klee — LLVM 位码符号虚拟机，行为差异/测试生成的基础设施。
2. **Z3（SMT 求解器）** — Microsoft Research — https://github.com/Z3Prover/z3 — 约束求解核心，支撑符号执行、等价检查、路径条件求解。
3. **CBMC（C/C++ 有界模型检查器）** — Diffblue / CProver（Daniel Kroening 等）— https://github.com/diffblue/cbmc — 把 C/C++ 程序与断言编码为 SAT 求解，验证数组越界、指针安全等行为性质。
4. **SeaHorn（LLVM 程序验证框架）** — UC Santa Cruz 等 — https://github.com/seahorn/seahorn — SMT 有界模型检查 + CHC 软件模型检查（不变式推断），可验证 LLM 生成代码。
5. **Why3（演绎程序验证平台）** — INRIA 等 — https://github.com/DSiSc/why3 — WhyML 规范语言 + 多后端定理证明器，生成并验证验证条件(VC)。
6. **Boogie（中间验证语言/框架）** — Microsoft Research — https://github.com/boogie-org/boogie — SymDiff、Dafny 等验证工具的共同中间层，行为等价检查的载体。
7. **SymDiff（差分程序验证器）** — Microsoft Research — https://www.microsoft.com/en-us/research/project/symdiff-differential-program-verifier/overview/ — 基于 Boogie 的双程序差分验证，直接实现程序行为等价/语义差异判定。
8. **angr（二进制分析框架）** — UC Santa Barbara — https://github.com/angr/angr — 二进制级符号执行与约束求解，可对编译后代码做行为分析。
9. **Rosette（求解器辅助语言）** — Brown University（Emina Torlak 等）— https://github.com/emina/rosette — Solver-aided host language，支持程序合成与等价/属性验证的 DSL 开发。
10. **ConcoLLMic（Agentic Concolic Execution）** — 开源社区项目 — https://github.com/ConcoLLMic/ConcoLLMic — LLM agent 驱动的混合执行，免去手写符号解释器，直接面向 LLM 代码验证。
11. **congruent-eq（有界等价检查器）** — 开源社区项目（satchmakua）— https://github.com/satchmakua/congruent-eq — 用差分测试 + Z3 符号执行证明 AI 重构函数与原函数行为等价或给出反例。
12. **Dafny（验证感知编程语言/验证器）** — Microsoft Research — https://github.com/dafny-lang/dafny — 自带规范语言与自动验证器，是"LLM 生成可验证代码"最常用目标语言之一。
