# 方向一：经验提取与形式化（审查后精选版）

> 研究子问题：如何从成功/失败的**执行实例**中自动提取模式、最佳实践或反模式，并将其转化为 **Spec 条款（L2）** 或 **实现约定（L3）**。
> 审查时间：2026-08-15。筛选标准：**三个月内（≥2026-05-15）新增 或 有重大意义**。所有条目均已核验为真实存在（无幻觉编号）。
