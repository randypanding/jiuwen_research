# 方向 2：程序行为/语义等价性的自动判据

> 搜索方向：程序等价检查、语义等价、行为等价、神经语义表示、等价判定。
> 本文件为原始搜集结果，不做分析。

## 学术论文（25 篇）

### A. 形式化等价验证 / 关系验证（Relational Verification）

1. **Semantic Program Alignment for Equivalence Checking** — Churchill, Padon, Sharma, Aiken（Stanford），PLDI 2019 — 基于语义而非语法构建 trace alignment 与 product program，将等价检查扩展到真实规模基准。
2. **Relational verification using product programs** — Barthe, Crespo, Kunz，FM 2011 — 用 product program 把关系验证（含程序等价）转化为标准验证问题。
3. **A Monadic Framework for Relational Verification Applied to Information Security, Program Equivalence, and Optimizations** — Maillard 等（F*），POPL 2019 — 单子化关系验证框架，统一处理程序等价与优化正确性。
4. **Exploiting Synchrony and Symmetry in Relational Verification** — Princeton，CAV 2018 — 利用同步与对称性约简关系验证（含等价检查）开销。
5. **An Algebra of Alignment for Relational Verification** — Antonopoulos 等（Yale），POPL 2023 — 用 BiKAT 代数统一描述对齐策略，支撑程序等价验证。
6. **A language-independent proof system for full program equivalence** — Formal Aspects of Computing，2016 — 以操作语义为参数的语言无关完全等价证明系统。
7. **Checking equivalence in a non-strict language** — Journal of Functional Programming — 基于符号执行+余归纳检查非严格函数式语言程序等价，工具 nebula。
8. **HEC: Equivalence Verification Checking for Code Transformation via Equality Saturation** — arXiv 2506.02290 — 用 e-graph/等值饱和在 MLIR 前端上验证代码变换的功能等价。
9. **Alive2: Bounded Translation Validation for LLVM** — Lopes, Menendez, Nagarakatte, Regehr，PLDI 2021 — 对 LLVM 优化变换做有界翻译验证（refinement 检查）。
10. **Regression Verification: Proving the Equivalence of Similar Programs** — Godlin, Strichman，CAV 2009 / STVR 2013 — 回归验证：证明新版本与旧版本行为等价（RVT 工具）。
11. **Differential Symbolic Execution** — Person, Dwyer, Elbaum, Păsăreanu，IEEE TSE 2008 — 通过符号执行同时探索两个版本的状态空间以刻画行为差异。
12. **Partition-Based Regression Verification** — Felsing, Grebing, Klebanov, Rümmer，ICSE 2013 — 用划分启发式处理回归验证中不可判定情形（PASDA）。
13. **Csmith: A Static-Dynamic-Equal Strategy for Random Testing of C Compilers** — Yang, Chen, Eide, Regehr，PLDI 2011 — 随机生成 C 程序，以差分测试作为等价/行为一致性判据发现编译器 bug。
14. **Semantic Code Search via Equational Reasoning** — Premtoon, Koppel, Solar-Lezama（MIT），PLDI 2018 — 基于数据流等式推理的语义代码搜索工具 Yogo，可识别数学等价的不同实现。
15. **Program Synthesis with Equivalence Reduction** — UW-Madison，VMCAI 2019 — 在程序合成搜索中用等价归约剪枝，等价类判定加速合成。

### B. 神经/学习式语义表示与等价判定

16. **code2vec: Learning Distributed Representations of Code** — Alon, Zilberstein, Levy, Yahav，POPL 2019 — 以方法名预测为代理任务学习代码分布式向量，用于语义属性预测。
17. **code2seq: Generating Sequences from Structured Representations of Code** — Alon 等，ICLR 2019 — 基于 AST 路径+注意力表示代码，可支撑语义相似/等价类任务。
18. **CodeBERT: A Pre-Trained Model for Programming and Natural Languages** — Feng 等，EMNLP 2020 Findings — 双模态预训练模型，广泛用于代码克隆（语义相似）检测等下游任务。
19. **GraphCodeBERT: Pre-training Code Representations with Data Flow** — Guo 等，ICLR 2021 — 引入数据流结构增强代码语义表示，用于语义克隆检测。
20. **ASTNN: A Novel Neural Source Code Representation Based on Abstract Syntax Tree** — Zhang 等，ICSE 2019 — 将 AST 拆分为语句树序列编码，用于代码克隆（含语义克隆）检测。
21. **CCLearner: A Deep Learning-Based Clone Detection Approach** — Li, Huang，ICSE 2018 — 纯 token 的深度学习克隆检测，可识别语义等价实现。
22. **EquiBench: Benchmarking Large Language Models' Reasoning about Program Semantics via Equivalence Checking** — arXiv 2502.12466 — 把等价检查作为评估 LLM 程序语义推理能力的新基准任务。
23. **Disproving Program Equivalence with LLMs** — Allamanis, Yin，2025 — 白盒、执行反馈驱动的 LLM 反证程序等价方法。
24. **On Neural Network Equivalence Checking using SMT Solvers** — arXiv 2203.11629 — 将神经网络等价检查编码为 SMT 公式求解。
25. **Emerge: Verify Implementation Equivalence of Large Models** — arXiv 2603.21851 — 用 e-graph + 执行值推断，检查大模型计算图实现的功能等价。

## 开源项目（12 个）

1. **code2vec**（官方实现，POPL'19）— https://github.com/tech-srl/code2vec — 学习代码分布式语义向量。
2. **code2seq**（官方实现，ICLR'19）— https://github.com/tech-srl/code2seq — AST 路径代码表示模型。
3. **ASTNN**（ICSE'19）— https://github.com/zhangj111/astnn — AST 子树编码做代码克隆检测。
4. **CCLearner**（ICSE'18）— https://github.com/liuqingli/CCLearner — 纯 token 深度学习克隆检测。
5. **CodeBERT**（含 GraphCodeBERT / UniXcoder）— https://github.com/microsoft/CodeBERT — 代码预训练模型族，支持克隆/语义相似检测。
6. **SymDiff**（微软）— https://github.com/boogie-org/symdiff — 差分/关系程序验证器，用于回归验证、翻译验证与超安全验证。
7. **Alive2**（PLDI'21）— https://github.com/AliveToolkit/alive2 — LLVM 变换的有界翻译验证/refinement 检查工具。
8. **Csmith**（PLDI'11）— https://github.com/csmith-project/csmith — 随机 C 程序生成器，以差分测试为等价判据。
9. **KLEE** — https://github.com/klee/klee — 符号执行引擎，可支撑差分符号执行与等价性分析。
10. **Yogo**（PLDI'18 工件）— https://zenodo.org/records/3743160 — 等式推理语义代码搜索工具（MIT）。
11. **roojs/semantic-code-search** — https://github.com/roojs/semantic-code-search — 基于 transformer 嵌入+余弦相似度的函数级语义代码搜索。
12. **sturdy-dev/semantic-code-search** — https://github.com/sturdy-dev/semantic-code-search — 基于 SentenceT5 在 code_search_net 上训练的语义代码搜索工具。
