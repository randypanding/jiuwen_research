# 方向 1：针对 LLM 生成代码的差分测试与评测

> 搜索方向：差分测试应用于 LLM 生成代码、用生成测试验证 LLM 代码、代码生成评测基准。
> 本文件为原始搜集结果，不做分析。

## 学术论文（22 篇）

### A. 核心：用生成测试 / 差分测试验证 LLM 生成代码

1. **CodeT: Code Generation with Generated Tests** — Bei Chen, Fengji Zhang 等（Microsoft Research Asia），ICLR 2023 — https://arxiv.org/abs/2207.10397 — 用同一 LLM 生成测试用例并执行，通过"代码-测试双一致"筛选正确代码，是以生成测试验证 LLM 代码的奠基工作。
2. **SelfEvolve: A Code Evolution Approach to Automated Differential Testing of Code Translation** — Tathagata Chakraborty, Saurabh Tiwary, Pankaj Dhoolia 等（IBM Research），2023 — https://arxiv.org/abs/2306.02907 — 用 LLM 生成测试用例对 LLM 翻译后的代码做差分测试并迭代修复翻译错误，与本方向最直接相关。
3. **Self-Debugging: Teaching Large Language Models to Self-Debug** — Xinyun Chen, Maxwell Lin, Nathanael Schärli, Denny Zhou（Google Research），ICLR 2024 — https://arxiv.org/abs/2304.05128 — 让 LLM 执行自己的代码、基于执行结果生成反馈并自修复。
4. **Coder-Reviewer Reranking for Code Generation** — Tianyi Zhang, Tao Yu, Tatsunori Hashimoto, Mike Lewis, Wen-tau Yih, Daniel Fried, Sida Wang（CMU/Google），ICML 2023 — https://arxiv.org/abs/2211.16490 — 代码生成器+评审器双模型对候选代码重排，结合可执行性过滤。
5. **LEVER: Learning to Verify Language-to-Code Generation with Execution** — Ansong Ni, Srini Iyer, Dragomir Radev, Veselin Stoyanov, Wen-tau Yih, Sida Wang, Xi Victoria Lin（Yale/Google），ICML 2023 — https://arxiv.org/abs/2302.08468 — 训练验证器基于程序执行结果判断代码正确性并重排候选。
6. **MBR-Exec: Natural Language to Code Translation with Execution** — Freda Shi, Daniel Fried, Marjan Ghazvininejad, Luke Zettlemoyer, Sida I. Wang（FAIR），ACL 2022 — https://arxiv.org/abs/2206.07581 — 用执行结果做最小贝叶斯风险（MBR）解码，选择通过测试的代码。
7. **Fault-Aware Neural Code Rankers (CodeRanker)** — Jeevana Priya Inala, Chenglong Wang 等（Microsoft Research），NeurIPS 2022 — https://arxiv.org/abs/2211.09427 — 训练神经排序器预测代码正确性（含错误类型），无需执行即可筛选代码。
8. **Sifting through the Chaff: On Utilizing Execution Feedback for Ranking the Generated Code Candidates (RankEF)** — ASE 2024 — https://dl.acm.org/doi/10.1145/3691620.3695000 — 用执行反馈做多任务学习，改进代码候选排序。
9. **Revisit Self-Debugging with Self-Generated Tests for Code Generation** — 2025 — https://arxiv.org/abs/2501.12793 — 系统研究"自生成测试+执行反馈"用于代码自调试的两种范式。
10. **ACE: Self-Evolving LLM Coding Framework via Adversarial Unit Test Generation and Preference Optimization** — 2026 — https://arxiv.org/abs/2605.16299 — 求解器-对抗器架构，用对抗性单元测试发现执行级失败并驱动自进化。

### B. 差分测试 / 模糊测试（LLM 辅助，含对 LLM 生成/翻译代码的验证）

11. **TitanFuzz: Large Language Models Are Zero-Shot Fuzzers: Fuzzing Deep-Learning Libraries via Large Language Models** — Yinlin Deng, Chunqiu Steven Xia, Haoran Peng, Chenyuan Yang, Lingming Zhang（UIUC），ISSTA 2023 — https://arxiv.org/abs/2305.12445 — 用 LLM 生成输入程序对 DL 库做差分/模糊测试，发现 65 个 bug。
12. **DLLens: Enhancing Differential Testing With LLMs For Testing Deep Learning Libraries** — Yinlin Deng 等（UIUC），TOSEM 2024 — https://arxiv.org/abs/2406.07944 — 用 LLM 合成跨库 API 对应（counterpart）做差分测试。
13. **DiffSpec: Differential Testing with LLMs using Natural Language Specifications and Code Artifacts** — 2024 — https://arxiv.org/abs/2410.04249 — 用自然语言规范+代码工件引导 LLM 生成差分测试，应用于 eBPF 与 Wasm 验证器。
14. **LWDIFF: An LLM-Assisted Differential Testing Framework for WebAssembly Runtimes** — ICSE 2025 — https://www.computer.org/csdl/proceedings-article/icse/2025/056900a769/251mHCEMl6U — 用 LLM 从 Wasm 规范提取知识、生成多阶段差分测试。
15. **RustAssure: Differential Symbolic Testing for LLM-Transpiled C-to-Rust Code** — Bai, Palit 等，2024 — https://www.semanticscholar.org/paper/b1de38975f0ab5e25f9dcea99572326aefaa15a2 — 对 LLM 转译的 C→Rust 代码做差分符号测试。
16. **Syzygy: Dual Code-Test C to (safe) Rust Translation using LLMs and Dynamic Analysis** — Manish Shetty, Naman Jain, Adwait Godbole, Sanjit Seshia, Koushik Sen（UC Berkeley），2024 — https://www.semanticscholar.org/paper/b1de38975f0ab5e25f9dcea99572326aefaa15a2 — 联合翻译代码与测试，用动态分析信息验证翻译等价性。
17. **Kaizen: Metamorphic Fuzzing and Differential Testing for LLM-Translated HPC Applications** — 2026 — https://arxiv.org/abs/2607.04058 — 对 LLM 翻译的 CUDA→OpenMP 代码做变形模糊+差分测试。
18. **tHinter: Guided Debugging of Auto-Translated Code Using Differential Testing** — 2025 — https://arxiv.org/abs/2501.09475 — 用 AFL++ 生成测试并对自动翻译代码做差分，定位导致输出差异的错误行。
19. **Fuzpiler: 基于 LLM 翻译与差分测试的跨语言编译器模糊测试** — 2026（中文期刊）— http://netinfo-security.org/CN/10.3969/j.issn.1671-1122.2026.04.007 — 用 LLM 将种子翻译为多语言等价程序，通过差分测试检测编译器行为不一致。

### C. 评测基准（用测试评估 LLM 代码）

20. **Is Your Code Generated by ChatGPT Really Correct? Rigorous Evaluation of Large Language Models for Code Generation (EvalPlus)** — Jiawei Liu, Chunqiu Steven Xia, Yuyao Wang, Lingming Zhang（UIUC），NeurIPS 2023 — https://lingming.web.illinois.edu/publications/neurips2023.pdf — 提出 EvalPlus，用 80x 更多测试严格评测 LLM 代码，揭示测试不足问题。
21. **LiveCodeBench: Holistic and Contamination Free Evaluation of Large Language Models for Code** — Naman Jain, King Han, Alex Gu 等（UC Berkeley），ICLR 2024 — https://arxiv.org/abs/2403.07974 — 持续收集新竞赛题，覆盖代码生成、自修复、代码执行、测试输出预测。
22. **BigCodeBench: Benchmarking Code Generation with Diverse Function Calls and Complex Instructions** — Terry Yue Zhuo 等（Monash/BigCode），ICLR 2025 — https://arxiv.org/abs/2406.15877 — 面向真实软件工程的 LLM 代码生成评测基准。
23. **TestEval: Benchmarking Large Language Models for Test Case Generation** — 2024 — https://arxiv.org/abs/2406.04531 — 评测 LLM 生成测试用例（覆盖率/分支/路径）能力的基准。
24. **RepoExec: Evaluate Code Generation with a Repository-Level Executable Benchmark** — 2024 — https://arxiv.org/abs/2406.11927 — 仓库级、可执行的代码生成评测基准。

> 另可参考（重要上下文/基准工作）：Self-Refine（NeurIPS 2023, arXiv:2303.17651）、Reflexion（NeurIPS 2023, arXiv:2303.11366）、AlphaCode（Science 2022, arXiv:2203.07814）、TransCoder（NeurIPS 2020, arXiv:2006.03511）、CRUXEval（ICLR 2024, arXiv:2401.03065）、SWE-bench（ICLR 2024, arXiv:2310.06770）、DS-1000（ICML 2023, arXiv:2211.11501）。
