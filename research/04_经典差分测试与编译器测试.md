# 方向 4：经典差分测试基础 + 编译器/解释器差分测试

> 搜索方向：差分测试奠基理论、编译器/解释器/JIT 差分测试、翻译验证、oracle 问题。
> 本文件为原始搜集结果，不做分析。

## 学术论文（20 篇）

### 奠基工作 / 理论

1. **Differential Testing for Software** — William M. McKeeman（DEC）— 1998 — Digital Technical Journal 10(1):100-107 — 差分测试奠基之作，首次系统提出以多个实现交叉比对输出作为测试预言（oracle），是 LLM 差分测试引擎的理论源头。
2. **Translation Validation** — Amir Pnueli, Michael Siegel, Eli Singerman — TACAS 1998 — https://dl.acm.org/doi/10.5555/646482.691453 — 翻译验证奠基工作，通过证明编译前后程序语义等价来验证编译器正确性，是差分/等价性检查的理论基础。
3. **The Oracle Problem in Software Testing: A Survey** — Earl T. Barr, Mark Harman, Phil McMinn, Muzammil Shahbaz, Shin Yoo — IEEE TSE 2015 — http://www.cs.ucl.ac.uk/staff/mharman/tse-oracle.pdf — 测试预言问题权威综述，将差分测试列为缓解 oracle 问题的核心途径之一。
4. **A Survey on Metamorphic Testing** — Sergio Segura, Gordon Fraser, Ana B. Sánchez, Antonio Ruiz-Cortés — IEEE TSE 2016 — 蜕变测试综述，用多执行结果间关系替代精确 oracle，与差分测试互补。

### 编译器差分测试 / 编译器 fuzzing

5. **Finding and Understanding Bugs in C Compilers** — Yang Chen, Alex Groce, Eric Eide, John Regehr — PLDI 2011 — http://www.stanford.edu/class/cs343/resources/finding-bugs-compilers-annotated.pdf — 提出 Csmith 随机程序生成器 + 差分测试，发现 GCC/LLVM 大量误编译 bug，PLDI 最具影响力论文奖。
6. **Taming Compiler Fuzzers** — Yang Chen, Alex Groce, Chaoqiang Zhang, Weng-Keen Wong, Xiaoli Fern, Eric Eide, John Regehr — PLDI 2013 — 用 delta debugging 最小化编译器差分测试失败用例，提升 bug 报告质量。
7. **Compiler Validation via Equivalence Modulo Inputs** — Vu Le, Mehrdad Afshari, Zhendong Su — PLDI 2014 — https://web.cs.ucdavis.edu/~su/publications/emi.pdf — 提出 EMI 技术：生成"对给定输入等价"的程序变体做差分测试，可精准打击优化阶段误编译。
8. **Many-core Compiler Fuzzing** — Christopher Lidbury, Andrei Lascu, Nathan Chong, Alastair F. Donaldson — PLDI 2015 — GLF/GraphicsFuzz 对 GPU 编译器（GLSL）做差分测试，发现大量驱动/编译器 bug。
9. **Finding Deep Compiler Bugs via Guided Stochastic Program Mutation** — Vu Le, Chengnian Sun, Zhendong Su — OOPSLA 2015 — 引导式随机程序变异（Athena），深化 EMI 思路发现深层编译器 bug。
10. **Toward Understanding Compiler Bugs in GCC and LLVM** — Chengnian Sun, Vu Le, Qirun Zhang, Zhendong Su — ISSTA 2016 — https://dl.acm.org/doi/pdf/10.1145/2931037.2931074 — 对 GCC/LLVM 编译器 bug 的实证研究，为差分测试设计提供 bug 特征依据。
11. **Random Testing for C and C++ Compilers with YARPGen** — Vsevolod Livinskii, Dmitry Babokin, John Regehr — OOPSLA 2020 — https://www-old.cs.utah.edu/~regehr/yarpgen-oopsla20.pdf — YARPGen 随机程序生成器，无需动态检查即可避免未定义行为，配合差分测试发现 220+ 编译器 bug。
12. **A Survey of Compiler Testing** — Junjie Chen, Jibesh Patra, Michael Pradel, Yingfei Xiong, Hongyu Zhang, Dan Hao — ACM Computing Surveys 2020 — 编译器测试权威综述，系统分类差分测试、等价性检查、fuzzing 等方法。

### 解释器 / JIT / JS 引擎差分测试

13. **Fuzzing with Code Fragments** — Christian Holler, Kim Herzig, Andreas Zeller — USENIX Security 2012 — LangFuzz 语法感知 fuzzing，用已知 bug 代码片段变异生成 JS 输入，发现 100+ 漏洞。
14. **Exposing Bugs in JavaScript Engines through Test Transplantation and Differential Testing** — 2021 — https://www.arxiv.org/pdf/2012.03759 — 将测试移植与差分测试结合，跨引擎暴露 JS 引擎功能 bug。
15. **Automated Conformance Testing for JavaScript Engines via Deep Compiler Fuzzing** — PLDI 2021 — https://dl.acm.org/doi/pdf/10.1145/3453483.3454054 — COMFORT 对 10 个主流 JS 引擎做差分一致性测试，发现 158 个 bug。
16. **JIT-PICKING: Differential Fuzzing of JavaScript Engines** — CCS 2022 — https://dl.acm.org/doi/pdf/10.1145/3548606.3560624 — 让 JS 引擎"自己对自己"做差分测试：比较解释器与 JIT 编译器的运行行为，发现优化错误。
17. **FuzzJIT: Oracle-Enhanced Fuzzing for JavaScript Engine JIT Compiler** — USENIX Security 2023 — https://www.usenix.org/system/files/sec23summer_118-wang_junjie-prepub.pdf — 利用"JIT 只提速不改结果"这一 oracle 约束，暴露 JIT 编译 bug。
18. **DUMPLING: Fine-grained Differential JavaScript Engine Fuzzing** — NDSS 2025 — https://kitsec.org/pubs/2025-ndss.pdf — 对引擎内部做细粒度状态差分（frame dump），发现 V8 等引擎深层 bug。

### JVM / 其他语言实现差分测试

19. **Coverage-Directed Differential Testing of JVM Implementations** — Yuting Chen, Ting Su, Chengnian Sun, Zhendong Su, Jianjun Zhao — PLDI 2016 — https://www.cs.ucdavis.edu/~su/publications/pldi16.pdf — classfuzz 面向 JVM 启动过程的覆盖率引导差分测试。
20. **Deep Differential Testing of JVM Implementations** — Yuting Chen, Ting Su, Zhendong Su — ICSE 2019 — 深度学习引导的 JVM 差分测试（classming），深入测试字节码验证器与执行引擎。

## 开源项目（12 个）

1. **Csmith** — https://github.com/csmith-project/csmith — 随机 C 程序生成器，专为差分测试编译器设计。
2. **YARPGen** — https://github.com/LinkiTools/yarpgen — 随机 C/C++ 程序生成器，面向编译器优化 bug 的差分测试。
3. **AFL (American Fuzzy Lop)** — https://github.com/google/AFL — Michal Zalewski 开发的覆盖率引导模糊测试器，差分测试输入生成的常用引擎。
4. **AFL++** — https://github.com/AFLplusplus/AFLplusplus — AFL 的社区增强版，整合大量前沿 fuzzing 研究成果。
5. **libFuzzer** — https://llvm.org/docs/LibFuzzer.html — LLVM 进程内覆盖率引导 fuzzing 引擎，常用于编译器/解释器目标函数测试。
6. **KLEE** — https://klee.github.io — 符号执行引擎，可生成高覆盖率测试用例，支撑差分符号执行类方法。
7. **Fuzzilli** — https://github.com/googleprojectzero/fuzzilli — 基于 FuzzIL 中间语言的 JS 引擎 JIT fuzzer。
8. **Nautilus** — https://github.com/nautilus-fuzz/nautilus — 覆盖率引导的语法 fuzzer，NDSS 2019 论文配套工具。
9. **Grammarinator** — https://github.com/renatahodovan/grammarinator — 基于 ANTLR v4 语法的随机测试生成器，可生成语法正确的程序输入。
10. **JQF** — https://github.com/rohanpadhye/JQF — Java 反馈引导 fuzzing 平台（AFL/libFuzzer 的 JVM 版），支持属性测试驱动。
11. **jsfunfuzz / funfuzz** — https://github.com/MozillaSecurity/funfuzz — Mozilla 的 JS 引擎 fuzzing 套件，历史上发现 1000+ SpiderMonkey bug。
12. **GraphicsFuzz (GLF)** — https://github.com/google/graphicsfuzz — 面向 GPU 着色器编译器的差分测试框架（对应 Many-core Compiler Fuzzing 论文）。
