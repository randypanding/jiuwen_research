# 方向二：语义冲突的自动检测与合并策略

> 子问题：如何自动检测两个并发 Spec 修改在语义上的冲突（如对同一接口的不同契约变更），并提示人类或自动合并？
> 覆盖：语义合并引擎、schema 匹配/对齐、API breaking change 检测、结构化三方合并、LLM 合并、多 Agent 冲突。
> 审查日期：2026-08-15（已核验 URL、已剔除灰色来源、已补 2026 新内容）

## 四、论文清单（经典/奠基，保留）

1. **[经典/奠基] Semistructured Merge: Rethinking Merge in Revision Control Systems（FSTMERGE）** — Apel 等, ESEC/FSE 2011
   URL: http://www.cs.cmu.edu/~ckaestne/pdf/esec11.pdf
   相关性：语义级（半结构化）合并奠基论文，用语法树+冲突解决规则合并不同修订。

2. **[经典] IntelliMerge: A Refactoring-Aware Software Merging Technique** — OOPSLA 2019
   URL: https://dl.acm.org/doi/pdf/10.1145/3360596
   相关性：基于程序单元图（PEG）的图式三路合并，检测/规避重命名等重构相关语义冲突。

3. **[经典] Automatic Detection and Resolution of Software Merge Conflicts: Are We There Yet?** — Shen 等, 2021
   URL: https://arxiv.org/pdf/2102.11307.pdf
   相关性：系统对比文本/编译/动态三类冲突，评估现有工具检测盲区。

4. **[经典/重要] Evaluation of Version Control Merge Tools** — ASE 2024（Ernst 阵营）
   URL: https://homes.cs.washington.edu/~mernst/pubs/merge-evaluation-ase2024.pdf
   相关性：大规模评测语义合并工具，含冲突正确性/精确率数据。

5. **[经典] On the Methodology of Three-Way Structured Merge in Version Control Systems: Top-Down, Bottom-Up, or Both** — SETTA 2022
   URL: https://namasikanam.github.io/papers/setta2022.pdf
   相关性：结构化三路合并算法方法论。

6. **[经典] Real Differences between OT and CRDT under a General Transformation Framework** — 2019
   URL: https://arxiv.org/pdf/1905.01518v2
   相关性：实时协作编辑两大一致性技术路线比较。

7. **[经典] Operation-based Refactoring-aware Merging: An Empirical Evaluation** — Ellis 等, TSE 2023
   URL: https://sanadlab.org/assets/pdf/EllisTSE2023.pdf
   相关性：经验评估基于操作的重构感知合并。

8. **[经典/重要] LLMatch: a Unified Schema Matching Framework with Large Language Models** — 2025
   URL: https://arxiv.org/html/2507.10897v1
   相关性：用 LLM 做 schema 匹配/对齐。

9. **[经典] Extensible Conflict-Free Replicated Datatypes for Real-time Collaborative Software Engineering** — 2022
   URL: https://etsannals.org/proceedings/2022/drp/pdf/99.pdf
   相关性：面向实时协同软件工程的 CRDT 框架。（内容价值一般，可作补充）

10. **[经典] A Rule-Based Language for Configurable N-way Model Matching（CPL）** — 2020
    URL: https://www.semanticscholar.org/paper/af6e625508ffe1815003a98ba1d0ed5d8259313b
    相关性：规则语言描述模型合并中的语法/语义冲突。
