## 四、核心结论

1. **本主题最直接回答"成本-效果平衡"的论文是 ACM（二次成本经济学建模）、Don't Break the Cache（缓存量化）、ACON（压缩+蒸馏）、TokenPilot（缓存+压缩）、DACS（swarm 上下文隔离量化）**，共同构成"缓存+压缩+并行+预算"的完整工具箱。

2. **开源侧最贴合的是 TencentDB Agent Memory（-61% token 实测）、Mem0（token-efficient 算法）、Graphiti（免摘要混合检索）、JiuwenSwarm（团队 token 预算一等公民）、LangGraph（checkpoint 断点续跑）、OpenAI Agents SDK（session 限长/裁剪/压缩三件套）**。

3. **背景级条目中，CompLLM 与 Agent Memory Below the Prompt 应上调为 A 档**（复用性软压缩、多 agent KV 持久化），证实了"背景"复审的必要性。

4. **关键工程警示**：Lost in the Middle 系列表明"塞更多上下文不等于更准"，盲目压缩也可能触发位置偏差——成本-效果平衡必须同时权衡上下文长度、位置与缓存连续性。

5. **弃用/低价值项**：OpenAI Swarm 已弃用（用 Agents SDK 替代）；llm-cost、Sentinel Tokens、1-2-3 Check 与本主题相关性低，仅作参考不建议采用。
