# 方向 3：测试输入智能生成 + 差分测试与属性测试融合

> 搜索方向：(A) 用 LLM 或 fuzzing 自动生成能暴露行为差异的测试用例；(B) 差分测试与属性测试(PBT)的融合。
> 本文件为原始搜集结果，不做分析。

## 方向 A：测试输入的智能生成（25 篇）

1. **TitanFuzz: Large Language Models are Zero-Shot Fuzzers: Fuzzing Deep-Learning Libraries via Large Language Models** — Yinlin Deng, Chunqiu Steven Xia, Haoran Peng, Chenyuan Yang, Lingming Zhang (UIUC/USTC) — ISSTA 2023 — https://arxiv.org/pdf/2212.14834v4.pdf — 用 LLM 零样本生成并变异深度学习库 API 调用作为测试输入，配合差分执行暴露库间行为差异。
2. **WhiteFox: White-Box Compiler Fuzzing Empowered by Large Language Models** — Chenyuan Yang, Yinlin Deng, Runyu Lu, Jiayi Yao, Jiawei Liu, Reyhaneh Jabbarvand, Lingming Zhang (UIUC) — OOPSLA 2024 — https://arxiv.org/abs/2310.15991 — LLM 分析编译器优化源码后生成能触发深层优化的测试程序，发现 DL 编译器大量 bug。
3. **FuzzGPT: Fuzzing Deep Learning Libraries via Large Language Models** — Yinlin Deng et al. (UIUC) — 2023 — arXiv — 基于 LLM 生成"异常/罕见"程序作为模糊输入，用于 DL 库测试。
4. **ChatFuzz: Augmenting Greybox Fuzzing with Generative AI** — 2023 — https://ar5iv.labs.arxiv.org/html/2306.06782 — 用 ChatGPT 对种子进行变异生成格式合规的高质量输入，增强灰盒模糊测试。
5. **CodaMosa: Escaping Coverage Plateaus in Test Generation with Pre-trained Large Language Models** — Caroline Lemieux, Jeevana Priya Inala, Shuvendu Lahiri, Siddhartha Sen (Microsoft Research) — ICSE 2023 — https://www.microsoft.com/en-us/research/publication/codamosa-escaping-coverage-plateaus-in-test-generation-with-pre-trained-large-language-models/ — 将 LLM 生成的示例测试融入搜索式测试生成(SBST)以突破覆盖率平台。
6. **TestPilot: An Empirical Evaluation of Using Large Language Models for Automated Unit Test Generation** — Max Schäfer et al. (Meta) — IEEE TSE — https://www.franktip.org/pubs/testpilot2023.pdf — 用 LLM 为 JavaScript API 自动生成单元测试，达到高语句/分支覆盖率。
7. **ChatUniTest: A Framework for LLM-Based Test Generation** — 2023 — https://arxiv.org/html/2305.04764v2 — 基于 LLM 的 Java 单元测试生成框架，结合覆盖率反馈迭代优化。
8. **CoverUp: Coverage-Guided LLM-Based Test Generation** — 2024 — https://arxiv.org/pdf/2403.16218 — 以覆盖率作为反馈循环引导 LLM 迭代生成测试，超越 EvoSuite 等传统工具。
9. **ELFuzz: Efficient Input Generation via LLM-driven Synthesis Over Fuzzer Space** — USENIX Security 2025 — https://www.usenix.org/system/files/usenixsecurity25-chen-chuyang.pdf — 通过 LLM 在"模糊器空间"中进化合成面向被测系统的生成式模糊器。
10. **Mokav: Execution-driven Differential Testing with LLMs** — 2024 — https://arxiv.org/html/2406.10375v2 — 用 LLM 生成"差异暴露测试"(DET)，执行驱动地检测两个程序版本间的功能差异。
11. **DiffSpec: Differential testing with LLMs using Natural Language Specifications and Code Artifacts** — 2024 — https://arxiv.org/pdf/2410.04249v3 — 用自然语言规范与代码工件引导 LLM 生成能凸显实现间行为差异的差分测试。
12. **MutGen: Mutation-Guided Unit Test Generation With a Large Language Model** — IEEE TSE 2026 — https://store.computer.org/csdl/journal/ts/2026/05/11478734/2fzptwnimcw — 将变异反馈直接融入提示词，迭代生成能杀死更多变异体的 LLM 测试用例。
13. **CodeGraphGPT: A Code Knowledge Graph-Enhanced System for LLM-Based Fuzz Driver Generation** — 2024 — https://arxiv.org/html/2411.11532v1 — 用代码知识图谱增强 LLM 智能体自动生成模糊驱动(fuzz driver)。
14. **PromeFuzz: A Knowledge-Driven Approach to Fuzzing Harness Generation with Large Language Models** — 2025 — https://dl.acm.org/doi/10.1145/3719027.3765222 — 结合代码元数据/API 文档/调用关联构建知识库，RAG 增强生成模糊 harness。
15. **SAFuzz: Semantic-Guided Adaptive Fuzzing for LLM-Generated Code** — 2025 — https://www.themoonlight.io/fr/review/safuzz-semantic-guided-adaptive-fuzzing-for-llm-generated-code — 语义引导的自适应模糊测试，高效检测 LLM 生成代码中的算法漏洞。
16. **Kaizen: Metamorphic Fuzzing and Differential Testing for LLM-Translated HPC Applications** — 2026 — https://arxiv.org/abs/2607.04058 — 对 LLM 翻译的 HPC 代码做蜕变模糊+差分测试，暴露"编译通过但结果错误"的语义分歧。
17. **NEZHA: Efficient Domain-Independent Differential Testing** — Matteo Paltenghi, Michael Pradel — ICSE 2017 — http://www.cs.columbia.edu/~angelos/Papers/2017/nezha.pdf — 提出 δ-多样性指标引导输入生成，领域无关的差分测试框架。
18. **DLFuzz: Differential Fuzzing Testing of Deep Learning Systems** — ESEC/FSE 2018 — https://dl.acm.org/doi/pdf/10.1145/3236024.3264835 — 通过最大化神经元覆盖与预测差异引导变异，差分模糊测试 DL 系统。
19. **Evolutionary Generative Fuzzing for Differential Testing of the Kotlin Compiler** — ISSTA 2023 — https://pure.tudelft.nl/ws/portalfiles/portal/216990626/3663529.3663864.pdf — 进化生成式模糊测试对 Kotlin 编译器做差分测试，绕过 oracle 问题。
20. **Towards Translating Real-World Code with LLMs: A Study of Translating to Rust** — 2024 — https://arxiv.org/html/2405.11514v2 — 构建跨语言差分模糊器验证 LLM 代码翻译与原程序的 I/O 等价性。
21. **A Differential Fuzzing-Based Evaluation of Functional Equivalence in LLM-Generated Code Refactorings** — 2026 — https://arxiv.deeppaper.ai/papers/2602.15761v1 — 用差分模糊检查 LLM 重构代码与原始实现的功能等价性，无需预定义测试用例。
22. **LLMs in the Heart of Differential Testing: A Case Study on a Medical Rule Engine** — 2024 — https://arxiv.org/pdf/2404.03664v3 — LLM 生成测试输入用于医疗规则引擎的差分测试。
23. **基于大语言模型的模糊测试研究综述** — 《软件学报》2025 — https://www.jos.org.cn/html/2025/6/7323.htm — 系统综述 LLM 在模糊测试中的应用，归纳 LLM 生成测试输入的 3 类方法（微调/提示工程/传统算法融合）。
24. **A Review of Large Language Models for Automated Test Case Generation** — MDPI Machine Learning and Knowledge Extraction 2025 — https://mdpi-res.com/d_attachment/make/make-07-00097/article_deploy/make-07-00097.pdf — 综述 LLM 自动化测试用例生成的提示设计、反馈循环等方向。
25. **On the Challenges of Fuzzing Techniques via Large Language Models** — 2024 — https://arxiv.org/pdf/2402.00350v3 — 分析 LLM 驱动模糊测试（如 CHATAFL 协议模糊器）面临的核心挑战。

## 方向 B：差分测试与属性测试(PBT)的融合（18 篇）

1. **QuickCheck: A Lightweight Tool for Random Testing of Haskell Programs** — Koen Claessen, John Hughes — ICFP 2000 — https://asr.github.io/courses/cm0859-type-theory/2025-2/slides/testing-with-quickcheck.pdf — 属性测试(PBT)奠基之作，用随机生成+收缩(shrink)验证程序性质。
2. **To Kill a Mockingbird: A Framework for Test Oracle Generation** — Earl T. Barr, Mark Harman, Phil McMinn, Muzammil Shahbaz, Shin Yoo — ICSE 2015 — https://dl.acm.org/doi/10.1145/2786805.2786873 — 自动生成测试预言：以简化参考实现(mock)作为 oracle，本质是差分式 oracle，缓解 oracle 问题。
3. **Mica: Automated Differential Testing for OCaml Modules** — 2024 — https://arxiv.org/html/2408.14561v1 — 基于 Jane Street Core.Quickcheck 自动派生 PBT 代码检查 OCaml 模块的观测等价性，是差分测试与属性测试融合的典型。
4. **Property-Based Testing in Practice** — Harrison Goldstein et al. (Jane Street) — ICSE 2024 — https://harrisongoldste.in/papers/icse24-pbt-in-practice.pdf — 对 Jane Street 等工业界 PBT 实践的实证研究。
5. **An Empirical Evaluation of Property-Based Testing in Python** — OOPSLA 2025 — https://cseweb.ucsd.edu/~mcoblenz/assets/pdf/OOPSLA_2025_PBT.pdf — 对 Python 生态中 Hypothesis 等 PBT 库使用情况的实证评估。
6. **Property-Based Testing Across Four Environments in Open-Source Repositories** — 2025 — https://sarajuhosova.com/assets/files/2025-pbt-in-the-wild.pdf — 跨 Java(JQwik)/Python(Hypothesis)/Rust(proptest、QuickCheck)研究 PBT 在开源库中的使用模式，包括"与 oracle 等价"类属性。
7. **How Developers Implement Property-Based Tests** — 2023 — https://www.researchgate.net/profile/Arthur-Corgozinho/publication/373829403_How_Developers_Implement_Property-Based_Tests/links/64ff10f6849bbb203b90fb92/How-Developers-Implement-Property-Based-Tests.pdf — 研究开发者如何用 Hypothesis 实现属性测试。
8. **PBT-Bench: Benchmarking AI Agents on Property-Based Testing** — 2026 — https://arxiv.org/html/2605.15229v1 — 评测 AI 智能体自动编写属性测试的能力，涉及 Hypothesis 等框架。
9. **Agentic Property-Based Testing: Finding Bugs Across the Python Ecosystem** — 2025 — https://arxiv.org/pdf/2510.09907 — 编码智能体自主爬取代码库、发现高价值属性、编写并运行 PBT 来定位 bug。
10. **PropTest: Automatic Property Testing for Improved Visual Programming** — 2024 — https://arxiv.org/html/2403.16921v1 — 自动生成属性测试用例作为反馈引导 LLM 视觉编程代码生成。
11. **METAL: Metamorphic Testing Framework for Analyzing Large-Language Model Qualities** — 2023 — https://arxiv.org/pdf/2312.06056v1.pdf — 用蜕变关系(MR)系统测试 LLM 质量，与 PBT 的"性质验证"思想相通。
12. **MetaFOE: Investigating Metamorphic Fuzz Oracle Enhancement via Large Language Models** — 2026 — https://arxiv.org/abs/2606.14164 — LLM 自动生成并集成蜕变 oracle，增强 OSS-Fuzz 驱动的模糊测试。
13. **Towards Generating Executable Metamorphic Relations Using Large Language Models** — 2024 — https://arxiv.org/html/2401.17019 — 用提示工程教 LLM 从需求生成可执行蜕变关系(EMR)。
14. **Variable Discovery with Large Language Models for Metamorphic Testing of Scientific Software** — ICCS 2023 — https://www.iccs-meeting.org/archive/iccs2023/papers/140730328.pdf — 用 LLM 为科学计算软件发现蜕变关系变量，缓解 oracle 问题。
15. **Bidirectional Empowerment of Metamorphic Testing and Large Language Models: A Systematic Survey** — 2025 — https://www.themoonlight.io/de/review/bidirectional-empowerment-of-metamorphic-testing-and-large-language-models-a-systematic-survey — 系统综述 93 篇蜕变测试与 LLM 双向赋能的研究。
16. **Drowzee: Metamorphic Testing for Fact-Conflicting Hallucination Detection in Large Language Models** — 2024 — https://arxiv.org/html/2405.00648v2 — 用蜕变关系检测 LLM 事实冲突幻觉。
17. **From Prompts to Properties: Rethinking LLM Code Generation with Property-Based Testing** — 2025 — https://chbrown13.github.io/papers/autopydep.pdf — 用 Hypothesis 为 LLM 生成代码定义并验证性质（如排序输出有序性）。
18. **Testing Noninterference, Quickly** — 2014 — https://arxiv.org/pdf/1409.0393v1.pdf — 用 QuickCheck 形式化并测试抽象机的非干扰安全属性。

## 开源项目（15 个）

1. **Hypothesis** (Python) — https://github.com/degustaf/hypothesis — 最流行的 QuickCheck 风格 Python 属性测试库，支持生成器组合、收缩、状态化测试。
2. **QuickCheck** (Haskell) — https://hackage.haskell.org/package/QuickCheck-2.18.0.0 — 属性测试原始实现，PBT 范式源头。
3. **proptest** (Rust) — https://github.com/proptest-rs/proptest — Rust 生态主流 PBT 库，支持策略组合与收缩。
4. **quickcheck** (Rust) — https://github.com/BurntSushi/quickcheck — Rust 版 QuickCheck 移植，Rust 两大 PBT 库之一。
5. **jqwik** (Java) — https://github.com/jqwik-team/jqwik — Java/JUnit 5 属性测试库。
6. **AFL++** — https://github.com/AFLplusplus/AFLplusplus — 覆盖率引导灰盒模糊测试的事实标准，广泛用于生成暴露崩溃/行为差异的输入。
7. **libFuzzer** — LLVM 项目 — https://llvm.org/docs/LibFuzzer.html — 进程内覆盖率引导模糊器，与 Sanitizer 配合。
8. **EvoSuite** — https://github.com/STAMP-project/evosuite — 搜索式单元测试生成工具，常作为 LLM 测试生成方法的对比基线。
9. **Randoop** — https://github.com/randoop/randoop — 基于反馈的随机回归测试生成工具。
10. **KLEE** — https://github.com/klee/klee — 符号执行驱动的高覆盖测试输入生成引擎。
11. **WhiteFox** — https://yangchenyuan.github.io/files/WhiteFox-OOSPLA-24-slides.pdf — LLM 白盒编译器模糊测试工具（OOPSLA 2024 配套开源）。
12. **TitanFuzz** — https://github.com/ise-uiuc/TitanFuzz — LLM 零样本模糊测试 DL 库工具（ISSTA 2023 配套开源）。
13. **FuzzGPT** — https://github.com/ise-uiuc/FuzzGPT — LLM 生成异常程序模糊 DL 库工具。
14. **CodaMosa** — https://www.microsoft.com/en-us/research/publication/codamosa-escaping-coverage-plateaus-in-test-generation-with-pre-trained-large-language-models/ — LLM+搜索式测试生成工具（ICSE 2023 配套开源）。
15. **Cryptofuzz** — https://github.com/guidovranken/cryptofuzz — 密码学库差分测试框架，支持自差分与跨库差分，集成于 OSS-Fuzz。

## 备注

- 部分论文（如 FuzzGPT、ChatUniTest、MutGen 等）的 arXiv 编号/期刊卷期以检索到的来源页为准。
- "To Kill a Mockingbird" 论文因检索被同名小说干扰，其出处（ICSE 2015, Barr/Harman/McMinn/Shahbaz/Yoo）为公认信息，建议后续核实 DOI。
