## 一、长上下文模型基准与评测（如何评估）

### 核心基准

1. **RULER: What's the Real Context Size of Your Long-Context Language Models?** 【✔ 重大】
   - 作者：Hsieh et al., 2024
   - 出处：https://arxiv.org/html/2404.06654v1
   - 相关性：提出"有效上下文长度"概念，通过需检索/多跳/聚合等合成任务测量模型真实可用长度，是评估长上下文能力的标杆。

2. **LongBench: A Bilingual, Multitask Benchmark for Long Context Understanding** 【✔ 重大】
   - 作者：Bai et al., 2023
   - 出处：GitHub：https://github.com/THUDM/LongBench
   - 相关性：经典中英双语多任务长上下文基准，涵盖单/多文档QA、摘要、few-shot、合成任务与代码补全。

3. **∞Bench (InfiniteBench): Extending Long Context Evaluation Beyond 100K Tokens** 【✔ 重大】
   - 作者：Zhang et al., 2024（清华）
   - 出处：GitHub：https://github.com/openbmb/infinitebench
   - 相关性：100K+ 长文本评测，12 个子任务覆盖 5 项长上下文能力。

4. **Long Code Arena: A Set of Benchmarks for Long-Context Code Models** 【✔ 重大】
   - 年份：2024（JetBrains Research）
   - 出处：https://arxiv.org/pdf/2406.11612
   - 相关性：面向长上下文**代码**模型的多任务基准，含仓库级补全与跨文件依赖，与代码库场景直接相关。

5. **BABILong: Long Context Reasoning-in-a-Haystack** 【✔ 重大】
   - 作者：Kuratov et al., 2024
   - 出处：https://arxiv.org/html/2406.10149v1
   - 相关性：在极长文档中测试事实推理极限，评估"长上下文中的检索/推理"。

6. **LongBench: Are de facto Long-Context Benchmarks Literally Evaluating Long-Context Ability?** 【✔ 近3个月相关】
   - 年份：2025
   - 出处：https://arxiv.org/pdf/2505.19293
   - 相关性：批判性研究，指出多数长上下文基准实际测不到"长上下文能力"（受基线推理能力混淆）——对"如何正确评估"有方法论价值。

7. **What is Wrong with Perplexity for Long-context Language Modeling?（LongPPL）** 【✔ 重大】
   - 年份：2024
   - 出处：https://arxiv.org/pdf/2410.23771v3 ；代码：https://github.com/PKU-ML/LongPPL
   - 相关性：提出 LongPPL 指标替代困惑度，避免 PPL 被稀疏/位置偏差误导。

8. **Marathon: A Race Through the Realm of Long Context** 【✔ 重大】
   - 作者：Lei Zhang 等（ACL 2024）
   - 出处：https://arxiv.org/html/2312.09542 ；https://aclanthology.org/2024.acl-long.284
   - 相关性：长上下文评测并对比压缩(LLMLingua)与 RAG 两类优化手段，直接回答"压缩 vs 检索哪个更优"。

9. **MathHay: An Automated Benchmark for Long-Context Mathematical Reasoning** 【✔ 近3个月相关】
   - 年份：2024
   - 出处：https://arxiv.org/pdf/2410.04698 ；代码：https://github.com/leiwang-sf/MathHay
   - 相关性：面向长上下文数学推理的自动化基准（正式名 MathHay）。

### 代码仓库级评测（近 3 个月新增）

10. **ReCUBE: Evaluating Repository-Level Context Utilization in Code Generation** 【✔ 近3个月 · 高优先级】
    - 年份：2026
    - 出处：https://arxiv.org/abs/2603.25770 ；代码：https://github.com/JiseungHong/ReCUBE
    - 相关性：仓库级上下文利用率评测，对比 ∞Bench/SWE-Bench/Commit0 等既有基准的缺陷，附 CCE 工具包，直接服务于"代码库上下文管理"评估。

11. **SWE-bench** 【✔ 重大】
    - 作者：Jimenez et al., 2024
    - 出处：https://github.com/SWE-bench/SWE-bench
    - 相关性：真实代码库 issue 修复基准，是编码 agent 及上下文策略评估的事实标准。

12. **Do Context Files Help Coding Agents? A Two-Agent Ablation Study** 【✔ 近3个月 · 高优先级】
    - 年份：arXiv:2607.27250, 2026
    - 出处：https://arxiv.org/pdf/2607.27250
    - 相关性：在真实 repo 上对照测试 AGENTS.md 上下文注入策略（none/always_on/selective），结论是策略并不显著改变正确率，失败主因是实现技能非上下文——对"上下文注入是否有用"给出反直觉但关键的实证。

13. **Evaluating AGENTS.md: Are Repository-Level Context Files Helpful for Coding Agents?** 【✔ 近3个月 · 高优先级】
    - 年份：arXiv:2602.11988, 2026
    - 出处：https://arxiv.org/html/2602.11988v1
    - 相关性：系统评测 LLM 生成 vs 人工编写的 AGENTS.md 上下文文件，发现 LLM 生成的上下文文件平均降低成功率约 3%、推高推理成本 20%+——对"上下文文件的价值"给出量化结论。

## 二、上下文压缩与摘要（prompt compression）

### 核心方法

14. **LLMLingua: Compressing Prompts for Accelerated Inference** 【✔ 重大】
    - 作者：Jiang et al.（微软），EMNLP 2023
    - 出处：https://www.microsoft.com/en-us/research/project/llmlingua/
    - 相关性：经典的粗到细 prompt 压缩框架，用小模型困惑度信号 + 预算控制压缩提示词，是本方向奠基作。

15. **LLMLingua-2: Data Distillation for Faithful Task-Agnostic Prompt Compression** 【✔ 重大】
    - 作者：Pan et al., 2024
    - 出处：https://arxiv.org/pdf/2403.12968
    - 相关性：将压缩建模为 token 分类任务，数据蒸馏 + 双向编码提升保真度。

16. **LongLLMLingua: Prompt Compression in Long Context Scenarios** 【✔ 重大】
    - 作者：Jiang et al., 2023
    - 出处：https://arxiv.org/pdf/2310.06839
    - 相关性：面向长上下文场景的压缩，同时解决成本、位置偏差与关键信息密度问题。

17. **SelectiveContext** 【✔ 重大】
    - 作者：Li et al., EMNLP 2023
    - 出处：https://github.com/liyucheng09/Selective_Context
    - 相关性：基于自信息量的零参数压缩方法，配合语法解析保持连贯性。

18. **RECOMP: Improving Retrieval-Augmented LMs with Compression** 【✔ 重大】
    - 作者：Xu et al., 2023
    - 出处：https://arxiv.org/pdf/2312.10997
    - 相关性：训练"信息冷凝器"压缩检索文档，是"检索 + 压缩"结合的经典工作。

### 综述与实证

19. **Prompt Compression for Large Language Models: A Survey** 【✔ 重大】
    - 年份：2024
    - 出处：https://arxiv.org/pdf/2410.12388
    - 相关性：系统综述 prompt 压缩方法（硬性过滤 vs 软性改写），Sampling 导航首选。

20. **An Empirical Study on Prompt Compression for Large Language Models** 【✔ 近3个月相关】
    - 年份：2025（ICLR 2025 Workshop）
    - 出处：https://arxiv.org/pdf/2505.00019.pdf
    - 相关性：对 LLMLingua 系列等压缩方法的实证对比。

21. **Prompt Compression in Diffusion LLMs: Evaluating LLMLingua-2 on LLaDA** 【✔ 近3个月相关】
    - 年份：2026
    - 出处：https://arxiv.org/pdf/2605.17932v2
    - 相关性：将 LLMLingua-2 压缩评估扩展到扩散式 LLM（LLaDA），前沿补充。

22. **Characterizing Prompt Compression Methods for Long Context Inference** 【✔ 重大】
    - 年份：2024
    - 出处：https://www.arxiv.org/pdf/2407.08892
    - 相关性：系统刻画多种长上下文推理下的 prompt 压缩方法（含 PRCA、实体关系过滤等）。

### Agent 场景压缩（近 3 个月新增）

23. **Acon: Optimizing Context Compression for Long-horizon LLM Agents** 【✔ 近3个月 · 高优先级】
    - 年份：arXiv:2510.00615, 2025
    - 出处：https://arxiv.org/html/2510.00615v1
    - 相关性：统一框架系统性压缩交互历史与环境观察，压缩准则在自然语言空间优化，模型无关，峰值 token 降 26–54% 且保持/提升成功率。

24. **Cat: Context as a Tool — Context Management for Long-Horizon SWE-Agents** 【✔ 近3个月 · 高优先级】
    - 年份：arXiv:2512.22087, 2025
    - 出处：https://arxiv.org/html/2512.22087v1
    - 相关性：把上下文维护作为一等工具化能力，主动浓缩交互历史，轨迹级监督 + 离线改造流水线，SWE-Bench 验证。

## 三、检索增强生成（RAG）与长上下文结合

### 论文

25. **Retrieval Augmented Generation or Long-Context LLMs? A Comprehensive Study and Hybrid Approach** 【✔ 重大】
    - 作者：Zhuowan Li 等（EMNLP 2024 industry）
    - 出处：https://arxiv.org/abs/2407.16833
    - 相关性：系统对比 RAG 与长上下文 LLM，提出 RAG-or-LongContext 混合方案以兼顾成本与性能，是"RAG vs 长上下文"的核心决策参考。

26. **Long Context vs. RAG for LLMs: An Evaluation and Revisits** 【✔ 重大】
    - 作者：Xinze Li 等 (NTU/Fudan), 2025
    - 出处：https://arxiv.org/pdf/2501.01880v1
    - 相关性：重新评估长上下文窗口与 RAG 的性价比与适用场景。

27. **Retrieval-Augmented Generation for LLMs: A Survey** 【✔ 重大】
    - 作者：Gao et al., 2023
    - 出处：https://arxiv.org/pdf/2312.10997
    - 相关性：综述 RAG 三阶段范式，含 prompt 压缩与信息冷凝方法，RAG 方向导航首选。

28. **Retrieval-Augmented Generation: A Comprehensive Survey of Architectures, Enhancements, and Robustness Frontiers** 【✔ 近3个月相关】
    - 作者：Sharma, 2025
    - 出处：https://export.arxiv.org/pdf/2506.00054
    - 相关性：全面综述 RAG 架构、增强手段与鲁棒性前沿。

29. **Scaling Beyond Context: A Survey of Multimodal RAG for Document Understanding** 【背景参考】
    - 年份：2025
    - 出处：https://arxiv.org/html/2510.15253v2
    - 相关性：多模态 RAG 综述，涉及从 RAG 到记忆与长文档理解，与代码场景关联度较低，作背景。

30. **Graph of Records: Boosting RAG for Long-context Summarization with Graphs** 【背景参考】
    - 作者：Zhang et al., 2024
    - 出处：https://www.researchgate.net/publication/384938163
    - 相关性：图记录结构增强长上下文摘要，作背景。

## 四、上下文工程（Context Engineering）

31. **A Survey of Context Engineering for Large Language Models** 【✔ 重大】
    - 年份：2025
    - 出处：https://arxiv.org/html/2507.13334v2
    - 相关性：将上下文工程正式化为独立学科，提出组件与实现两层的系统化分类，是"上下文管理"总纲。

32. **Context Compression for Long-Horizon AI Agents: Lifecycle Management, Token Economics, and Production Patterns** 【✔ 近3个月相关】
    - 年份：2026
    - 出处：https://www.preprints.org/frontend/manuscript/24e8e17c1494ddf2261d9847dcf8db96/download_pub
    - 相关性：将上下文压缩重构为长时程 Agent 的生命周期管理（证据恢复、缓存前缀保持、Token 经济学）。

33. **Context Engineering: The Runtime Discipline Behind Production AI Agents（ACON）** 【✔ 近3个月相关】
    - 年份：2026
    - 出处：https://zylos.ai/research/2026-04-19-context-engineering-agent-runtime-discipline/
    - 相关性：介绍 ACON 梯度无关的压缩调优框架，无参数更新即可用任意 API 模型。

34. **CoMEM: Context Management with A Decoupled Long-Context Model** 【✔ 近3个月 · 高优先级】
    - 年份：arXiv:2605.30842, 2026
    - 出处：https://arxiv.org/pdf/2605.30842 ；代码：https://github.com/horizon-llm/CoMem
    - 相关性：将内存管理与主 agent 解耦并行执行，用异步流水线掩盖压缩延迟，奖励驱动训练内存模型——直接对应"长上下文模型利用 + 智能压缩"。

35. **Context Rot: Progressive Prompt Ephemerality** 【✔ 近3个月 · 高优先级】
    - 出处：https://empromptu.ai/resources/context-rot-progressive-prompt-ephemerality ；白盒研究：https://arxiv.org/pdf/2607.17937v2
    - 相关性：诊断上下文腐败（Context Rot）——累积无关内容导致输出退化，提出分层上下文架构。是"上下文管理提升生成质量"的核心动机。

## 五、Agent 记忆管理（记忆压缩与控制 Token 成本）

36. **MemGPT: Towards LLMs as Operating Systems** 【✔ 重大】
    - 作者：Packer et al., 2023
    - 出处：https://github.com/deductive-ai/MemGPT
    - 相关性：将上下文窗口类比为"内存"，通过显式 memory 函数在上下文与外部存储间搬运数据，管理长时程对话，是记忆分层管理的奠基作。

37. **Mem0** 【✔ 重大】
    - 组织：mem0ai
    - 出处：https://github.com/mem0ai/mem0
    - 相关性：开源通用 Agent 记忆层，分 User/Session/Agent 多级记忆，工业级广泛采用。

38. **A-Mem: Agentic Memory for LLM Agents** 【✔ 近3个月相关】
    - 年份：2025
    - 出处：https://arxiv.org/pdf/2502.12110
    - 相关性：基于 Zettelkasten 方法构建动态互连知识网络的 Agent 记忆系统。

39. **Context Compression for LLM Agents: A Survey of Methods, Failure Modes, and Evaluation** 【✔ 近3个月相关】
    - 年份：2026
    - 出处：https://www.preprints.org/manuscript/202605.2065
    - 相关性：综述 Agent 场景上下文压缩的方法、失败模式（细节丢失、压缩后访问失败）与评估。

## 六、上下文蒸馏（Context Distillation / 知识内化）

40. **Learning by Distilling Context** 【✔ 重大】
    - 年份：2022
    - 出处：https://ar5iv.labs.arxiv.org/html/2209.15189
    - 相关性：开创性工作：模型在完整上下文下生成输出，再仅凭裸输入微调内化上下文增益。

41. **Learning to Compress Prompts with Gist Tokens** 【✔ 重大】
    - 作者：Mu et al., 2023
    - 出处：https://arxiv.org/pdf/2304.08467
    - 相关性：通过学习"要点 token"（gist）压缩提示词，摊销推理期成本。

42. **Training Plug-and-Play Knowledge Modules with Deep Context Distillation** 【✔ 近3个月相关】
    - 作者：Caccia, Ansell, Ponti, Sordoni 等（COLM 2025）
    - 出处：https://arxiv.org/pdf/2503.08727v3.pdf
    - 相关性：深度上下文蒸馏训练"知识模块"，模拟含文档上下文的教师隐状态与 logits。

43. **On-Policy Context Distillation for Language Models** 【✔ 近3个月相关】
    - 年份：2026（微软）
    - 出处：https://arxiv.org/pdf/2602.12275
    - 相关性：在线策略蒸馏与上下文蒸馏结合，学生模型从自身生成轨迹学习内化上下文知识。

44. **OPSDL: On-Policy Self-Distillation for Long-Context Language Models** 【✔ 近3个月相关】
    - 年份：2026
    - 出处：https://arxiv.org/pdf/2604.17535
    - 相关性：面向长上下文模型的自蒸馏方法，引用 RULER 作为评测基准。
