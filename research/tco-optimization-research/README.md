# 多Agent系统TCO优化研究

本目录收录了围绕"多Agent系统总体拥有成本（TCO）优化"的完整研究材料，重点回答大规模并行（N值大）时的Token消耗与计算资源成本问题。

## 研究问题

> 如何优化多Agent系统的总体拥有成本（TCO），特别是在大规模并行（N值大）时的Token消耗和计算资源成本？

三个子问题：

1. **自适应Fan-out策略**：如何基于Spec的"不确定度"（历史返工率、领域新颖性、R级）动态调整N值，而非固定为常量？
2. **模型档位（RU）的智能路由**：如何根据任务复杂度和风险等级，将任务路由到不同成本的模型（Architect用高阶，Builder用中阶，Cartographer用低阶）？
3. **缓存与复用策略**：如何缓存和复用中间结果（已通过的Oracle测试结果、部分生成的代码片段），避免重复计算？
