# 00 证据标准与快照制度（包 0：R0.1 + R0.2）

> 归属任务清单：包0 R0.1「建立证据标准与快照制度」、R0.2「建立'事实易变度'分级」。
> 本文件是整个研究的**强制纪律**，所有后续交付物必须能通过本模板校验。

## 一、证据标准（R0.1）

### 1.1 每条厂商事实必须携带的字段

| 字段 | 必填 | 说明 |
|------|------|------|
| fact | 是 | 一句话客观陈述（不含推断） |
| source_url | 是 | 来源 URL（必须是可复核的原始链接） |
| captured_at | 是 | 抓取时间戳（YYYY-MM-DD） |
| quote | 是 | 原文引用片段（≤60 字，中文直译/原文双语） |
| confidence | 是 | 来源置信度分级（见 1.2） |
| half_life | 是 | 事实易变度/预期半衰期（见 2.1） |
| note | 否 | 备注 / 存疑点 / 待复核项 |

**规则**：
- 二手博客（分级 S）**不得作为唯一来源**；若某结论只有 S 级来源，必须显式标「仅社区二手，待官方核验」，不得进入结论性表格。
- 禁止编造 URL / 数字 / 引用。查不到就写「待核验」。
- 不同来源冲突时任选矛盾双方（O 优先），并保留冲突标注。

### 1.2 置信度分级

| 代码 | 含义 | 可否独立支撑结论 |
|------|------|------------------|
| **O** | 官方文档 / 官方公告 / 官方定价页 | 可 |
| **A** | 官方 API（Usage/Admin/限流响应头等，实测或文档） | 可 |
| **C** | 社区实测（真实用户的限流/用量截图、可复现脚本） | 可作为证据，结论需 O/A 佐证 |
| **S** | 二手博客 / 聚合帖 / 未经证实截图 | 不可独立，仅作线索 |

### 1.3 归档快照（与检查脚本配合）

- 每个关键页面建议留存：`web.archive.org` 时间戳快照，或本地 HTML 备份。
- 归档命名：`{vendor}_{topic}_{YYYYMMDD}.html`。
- 本批以「URL + captured_at + quote」为最小可核验单元；完整归档脚本见下方 `05` 节（独立脚本另行提交）。

## 二、事实易变度分级（R0.2）

### 2.1 半衰期分级

| 分级 | 预期半衰期 | 判定标准 | 复检频率建议 |
|------|-----------|----------|--------------|
| **短** | < 1 月 | 价格/限额/档位/重置语义/节流阈值 | 每周 |
| 中 | 1–3 月 | 厂商策略、非核心条款守则、工具配置 | 双周 |
| 长 | > 6 月 | 指标方法论、条款主干、schema、标准落点 | 每季度 |

示例：Anthropic 用额/限额 ≈ 短（4–8 周即可能变动）；PRV/PCV 定义 ≈ 长（方法论权威）。

### 2.2 结论性表格的「易变度标签」

所有结论性 `*.csv` / 矩阵单元格必须附 `Δ[短|中|长]` 标签，供后续抓复检队列。

## 三、证据表模板（CSV/JSONL schema）

以下为 `entitlements_v0.csv` / `capabilities_{vendor}.jsonl` 的字段统一 schema。

```csv
fact,source_url,captured_at,quote,confidence,half_life,note
通过该模板填写的证据表必须可由脚本做结构性校验（必填字段齐全、来源URL合法、置信度在{O,A,C,S}枚举内、时间戳为ISO格式）。
```

```jsonl
{"fact":"...","source_url":"...","captured_at":"2026-08-18","quote":"...","confidence":"O","half_life":"short","note":"..."}
```

## 四、证据真实性核验（把关点）

沿用仓库内 deepsearch 工作流已有的「精读总结+评分+纠错」惯例：
- 所有引用须子代理逐条 WebFetch 过、非凭记忆；
- 相同实体在不同视角下（论文/代码/实测）评分/置信度不同时，如实分别标注；
- 发现 URL 失效或号码错标，立即更正并在 note 注明。

## 五、归档脚本（独立文件）

归档/快照脚本建议单独提交为 `research/entitlement-valuation/scripts/snapshot.py`，功能：
- 输入 URL 列表 → 写 `web.archive.org` 快照请求 + 落本地 HTML
- 生成 `evidences.jsonl`（按本文档 schema），并在缺失必填字段时报错
- 输出「易变度复检队列」（按 half_life=short 排序）

> 注：脚本为建议项；本批交付为「模板 + 强制纪律」，脚本可在包7(R7.3 分发)一并实现。
