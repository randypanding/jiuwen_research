## 一、研究问题（以最新认知修订）

一句话：**「AI 订阅权益与承诺额度的度量与优化平台」**——先解决「你的订阅/承诺到底值多少钱、该不该换档/续约」，再做「在满足质量与延迟 SLO 的前提下，最小化真实现金支出」的调度与燃烧优化。

四层定位：
1. 本地优先的「寄生式计算器」（消费 ccusage/Claude-Code-Usage-Monitor 等既有输出为主）
2. 权益/承诺的「可执行注册表 Entitlement Registry」（对标 LiteLLM 的 model_prices_and_context_window.json）
3. 指标族与方法论权威（PRV / PCV / 利用率 / 易腐浪费 / 换档建议）
4. 活体面板与时效（厂商静默降配告警、Plan Value Index）
5. P3 重定位：企业承诺额度/预留容量燃烧优化（Bedrock/Azure PTU、Enterprise Commitment、Snowflake Credit）
