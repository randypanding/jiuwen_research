# 07 测试规范

> 原则：门禁与 oracle 本身必须被测试（"判据的可信度先于判据的使用"）。
> 现状：swarm-kernel 86 用例全绿；本文定义测试金字塔与各层门禁职责。

## 3. 差分测试的可信度保障

1. 同行为对照：good vs good2（不同写法同行为）必须判"无差分"（test_diff_engine）。
2. 异行为对照：divergent_a vs divergent_b 必须判"有差分"且定位到未定义区输入。
3. 确定性：同 seed 两次运行 pairwise 与 divergent_inputs 完全一致。
4. 模块缓存陷阱回归：多实例同进程加载必须 fresh-load（test_e2e silence 路径即为该回归的守护测试）。

## 4. oracle/门禁自身的测试义务

1. 每个门禁至少：1 正例（good 过）+ 1 反例（对应 bad 实例挡）；反例 fixture 永久保留在 fixtures/instances/。
2. 场景判分器：expectation 未知形态 = fail（防真空）；运行异常 = fail 不逃逸。
3. Wilson 判定器：边界用例（0/0、1/1、0/3、3/3、2/3）全覆盖。
4. 账本：篡改检测必须可复现（test_ledger_tamper_detected）。
5. judge：位置翻转不一致→abstain；veto 无引用→降级 abstain；脱敏断言（builder_identity/CoT 不入 judge）。

## 5. CI 中的测试门禁（工作流结构）

- 四层测试拆四个步骤（失败粒度到层）；
- 演示段钉退出码：good=0 / bad=1 / drift=1（防止门禁静默退化）；
- 任何对 swarm_kernel/contracts 的改动必须附 RuleProposal 引用，否则 CI 拒绝（由 CODEOWNERS + PR 模板检查实施）。

## 6. 目标域集成测试要求（T7/T8）

1. ACL rail 越权读取 → Guardrail 事件断言；
2. 临时团队 teardown 后会话目录不存在；
3. 波次状态机全路径（含补偿/回滚）；
4. 档位映射断言（judge 池 ≥ builder 池）。

```bash
cd swarm-kernel && python -m pytest tests -q            # 全量

python -m pytest tests/communication -q                  # 通信与隔离
python -m pytest tests/e2e -q                            # 全链路
./ci/run_all_gates.sh                                    # 门禁演示（含退出码断言）
swarm-kernel gates run --instance D --oracle O --spec S --out OUT --group G1 G2
swarm-kernel drift scan --spec S --root D
swarm-kernel admit commit --receipt R.json --world-root W
```
